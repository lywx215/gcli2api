# Opus 5.5 按凭证的权限保护

2026-10-04。本次只维护 Antigravity Opus 5.5 Low、Medium、High 及必要共享存储。
交付本地实现，不部署，不执行真实生成，不改变 Gemini CLI 或已终止的统一管理开发范围。

## 调用与恢复

模型按既有规则解析为精确上游 ID；裸名和 thinking 别名默认 Medium，功能前缀不改变档位。
凭证选择优先使用目录支持仍在 12 小时有效期内的凭证，再查询未知或过期候选。
最终发送前再次原子检查凭证代次、内容版本、每档权限和既有共享额度。
未经确认、存储不支持或没有合格凭证时，三种协议均使用已有本地 HTTP 503 契约；
流式、假流式及抗截断入口在响应头前返回 JSON。

有效目录缺少某档，或上游生成链路返回 HTTP/解析错误 404，只暂停对应凭证和档位。
暂停 24 小时，12 小时后复查；仍缺失则从复查时刻再暂停 24 小时。
暂停到期不会自行恢复。有效目录重新出现该档位时提前解除权限暂停，保留独立额度限制。
目录查询失败保留之前的证据和限制，15 分钟后再查。成功的指定凭证人工测试也可解除该档限制。

生成 404 不触发整凭证封禁，不依赖 SMART 429 开关；同一逻辑请求排除失败凭证，
在现有生成尝试上限内换号，不换档。已输出正文后不完整重试。
OAuth、项目查询和本地路由的 404 不触发模型权限暂停。
生成尝试仍采用现有统计结算；逻辑请求不因换号重复计数。目录查询不产生模型调用统计。

业务权限确认总预算 30 秒，单次查询 10 秒，目录查询并发最多 2，并受既有生成总时限约束。
确认预算耗尽仍可使用已确认的候选，未确认的候选由持久化计划进入后台。
服务内部调度器每分钟扫描，采用两个查询 worker 和 120 秒持久化租约；
重启后从数据库继续。禁用或永久禁用凭证不参与后台查询，不发送测试生成或重放对话。
不同 worker 的租约通过数据库原子操作竞争，数据库锁不跨越网络请求。

公开模型目录中的 Opus 部分来自启用凭证的有效支持证据并集，
不是随机选中一个凭证的 Opus 目录。其他模型保留原目录行为。
冷启动时未知权限不广告为支持；后台或按需查询建立证据后才加入并集。

## 存储增量迁移

新增独立 `antigravity_credentials.model_access_state` JSON 状态；MySQL 表为
`gcli_antigravity_credentials`，保留既有 server_name 隔离。每个精确 ID 保存状态、原因、
有效检查时间、最后查询尝试时间、暂停期限、下次检查时间和修订号；根状态保存身份摘要与复查租约。
外部面板只返回状态与时间，不返回身份摘要、租约、修订号或凭证内容。

- SQLite / PostgreSQL：新增 `TEXT DEFAULT '{}'` 列，新表与已有表均支持；缺列时幂等添加。
- MySQL：幂等新增 `LONGTEXT` 列；已有行的 NULL 作为未知处理，不重写旧行。
- MongoDB：不需要 DDL，缺失字段作为未知处理，首次观察时写入。

迁移不修改令牌、额度冷却、历史统计或 Management schema。查询和生成结果写入均以
凭证代次、完整内容版本、每档状态修订号作为约束。凭证替换和删除后重建使旧证据失效；
正常 token 刷新保留对应账号的既有权限暂停，但刷新前的网络结果不能覆盖新内容。
旧目录结果不能清除其发出后发生的 404；旧 404 不能覆盖页面重新确认的支持证据。

存储初始化确认字段可用后才声明 capability `antigravity.model_access.protection`。
Management schema 保持 1.4，动作枚举不变；manager 无需配套动作：`no_counterpart_action`。
无法确认存储支持时不声明该能力，Opus 业务请求按 503 处理。

## 面板与回滚

现有额度查询、批量刷新和模型目录查询复用同一次 `fetchAvailableModels` 响应更新三档状态。
原始模型/额度条目完整保留，不复制 4.6 的额度，也不制造缺失档位的卡片。
额度面板新增可选 `model_access_state`、`model_access_update` 字段；无模型卡片或查询失败时
仍显示每档状态、最近检查、下次复查和暂停期限。重新展开额度区可立即复查。
人工模型测试始终使用指定凭证，保持原测试响应兼容。

### 数百个凭证的总览与筛选

Antigravity 凭证列表直接显示 Opus 5.5 的 Low、Medium、High 标签，不用逐个展开额度。
列表上方汇总每档和组合条件的“目录支持 / 暂不可用 / 待确认”数量，覆盖全部分页。
总览计数遵循凭证状态、错误码、额度冷却、Tier 和备注筛选，但不受权限筛选影响，便于比较。
“目录支持”仅表示仍在 12 小时有效期内的支持证据；未查询、无有效支持证据或支持记录过期
为“待确认”。“暂不可用”是已有权限暂停，暂停到期不会改成支持。

快速使用：

1. 首次检查先选择“仅启用”，权限选择“全部状态”，点击“选择全部筛选结果”。
2. 点击“批量额度/权限检测（同步冷却）”；它查询目录并更新三档权限，同时执行已有额度冷却同步。
   不发送模型生成，不增加模型调用统计。弹窗区分查询成功/失败，并列出三档数量和每个凭证的状态；
   查询失败保留已有证据，不据此宣称无权限或恢复。
3. 档位选 High、Medium 或 Low，权限选“目录支持”，即可列出对应档位支持的全部凭证。
   权限选“暂不可用”查看暂停项，选“待确认 / 已过期”查看需要复查的项。
4. “至少一档”支持表示任一档支持，暂不可用表示三档均暂停，其余为待确认。
   “三档全部”支持表示三档都支持，暂不可用表示至少一档暂停，其余为待确认。
5. “全选本页”只选择当前页；“选择全部筛选结果”跨页选择，并替换之前的选择集合。
   可在筛选之后使用已有批量复制邮箱或下载操作，无需逐页勾选。

`GET /creds/status?mode=antigravity` 增加可选参数：
`model_access_filter=all|supported|unavailable|unknown`（默认 all），
`model_access_tier=any|all_tiers|low|medium|high`（默认 any）。权限筛选在后端分页之前执行。
响应增量字段为 `items[].model_access_state` 和 `model_access_summary`；后者包含总览范围的
`total`、快照分类时间 `checked_at`、各档/组合的 `counts`。原 `total/has_more` 对应筛选后的结果。
Gemini CLI 默认请求与分页保持原路径；非默认 Opus 筛选参数用于 Gemini CLI 时返回 400。

列表是数据库只读快照，不调用 Google、刷新 OAuth、修改权限、冷却或统计。
权限批量读取只有一次存储查询，包含禁用凭证，验证账号身份后只返回公开状态；
不返回令牌、凭证内容、身份摘要、租约或修订号。摘要与权限读取是两个只读快照，
并发更新时页面可能短暂显示旧状态，生成最终准入仍独立执行原子检查。
为跨页统计与筛选，Antigravity 在服务端对匹配摘要和权限作线性扫描，返回页仍最多 1000 条；
没有每个凭证单独查询的问题，也没有只筛选当前页的问题。
本增量复用已有 capability `antigravity.model_access.protection`，不增加存储字段或迁移。
Management schema 保持 1.4，动作枚举不变，manager 无需配套动作：`no_counterpart_action`。
无支持后端的列表归为待确认，不制造支持证据。

本增量完整隔离回归 **2159 项通过**；
桌面、手机与 601 个凭证的跨页验证见 [权限总览交付记录](delivery/opus-access-overview-20261004/README.md)。

回滚恢复本次代码即可；保留新增字段与原始数据，不删除、降级或改写生产数据。
旧版本不会读取这些权限状态，**不具备本次按凭证筛选和 404 保护**。
