# Antigravity Opus 按版本家族的凭证权限保护

当前规则更新于 2026-10-04。维护范围为 Antigravity Opus 5.5、4.6 及必要共享基础设施；
不恢复 Gemini CLI 专属开发或已终止的统一管理开发。本次为本地实现，历史部署及验收证据
不代表当前代码已部署。首次单版本切换记录见 [历史模型切换与部署记录](ANTIGRAVITY_OPUS_55.md)。

## 版本权限与请求模型

Opus 5.5 作为一个权限家族管理，Opus 4.6 有独立权限家族。面板不再按
Low / Medium / High 分成三份权限；这些名称仍保留在真实请求模型、额度卡片及路由目标中。

| 权限家族 | 实际上游模型 ID | 兼容名称 |
| --- | --- | --- |
| `claude-opus-5-5` | `claude-opus-5-5-low`、`claude-opus-5-5-medium`、`claude-opus-5-5-high` | 裸名及 `claude-opus-5-5-thinking` 默认 Medium |
| `claude-opus-4-6` | `claude-opus-4-6-thinking` | `claude-opus-4-6`、`claude-opus-4.6`、`claude-opus-4.6-thinking` |

有效目录含任意真实 5.5 ID 可确认该凭证的 5.5 家族权限，但只为实际返回的 ID 建立路由证据。
发送请求要求**家族权限和该精确 ID 的证据同时有效**；支持 Low 不能制造 High 的目录记录。
4.6 与 5.5 证据相互独立，缺少 5.5 不代表支持 4.6。明确请求的版本或档位不自动替换。
model routing 的公开名称仍映射固定目标，不能借权限合并改变请求身份或派发语义。

公开目录中的 Opus 模型来自启用凭证的有效精确路由证据并集；冷启动未知状态不广告为支持。
4.6 仅恢复真实 `thinking` ID，不创造 4.6 的 Low / Medium / High。原始额度保持原 ID 和数值，
不复制跨版本额度，也不制造目录缺失模型的卡片。其他模型维持既有目录行为。

## 调用、暂停与恢复

目录支持有效期为 12 小时。凭证选择优先使用有效支持证据，再查询未知或过期候选；
最终发送前原子验证凭证代次、内容版本、家族及精确路由证据，并独立检查共享额度限制。
未经确认、存储不支持或没有合格凭证时，沿用本地 HTTP 503；流式、假流式及抗截断入口
在响应头前返回 JSON。已输出正文后不重放完整请求，换凭证不改变模型版本或档位。

有效目录完全缺少一个版本，或该版本的生成返回 404，暂停对应凭证的**整个版本家族**。
暂停 24 小时，12 小时后复查；仍缺失则从复查时刻再暂停 24 小时。暂停到期不会自行恢复。
有效目录重新出现该版本的真实 ID 时可提前恢复家族权限；仅恢复目录确认的精确路由。
成功的指定凭证人工测试也可恢复该家族和测试的实际路由，独立额度限制保持生效。
目录查询失败保留已有证据与限制，15 分钟后再查。

生成 404 不触发整凭证封禁，不依赖 SMART 429 开关；同一逻辑请求排除失败凭证，
在既有尝试上限内换号。OAuth、项目查询及本地路由的 404 不触发生成权限暂停。
退休提示文本按生成错误处理，避免将其作为正常回答或成功统计；正常引用该文本不应误判。
目录查询不增加模型调用统计；换凭证不重复计算逻辑请求。

业务权限确认总预算 30 秒，单次查询 10 秒，目录查询并发最多 2，并受生成总时限约束。
内部调度器每分钟扫描，两个查询 worker 使用 120 秒持久租约；重启后继续复查计划。
禁用或永久禁用凭证不参与后台查询，不发送测试生成或重放对话。数据库锁不跨越网络请求。

## 存储 JSON v2 与旧状态兼容

本次复用既有 `model_access_state` 字段，**不增加数据库列或新表，也不批量改写旧行**。
原字段由此前权限保护实现引入：SQLite / PostgreSQL 为 TEXT，MySQL 为 LONGTEXT，
MongoDB 为文档字段；首次部署该历史基础设施时的初始化行为仍保留。
本次改变的是字段内 JSON 格式，`schema_version: 2` 包含：

- `families`：5.5 / 4.6 各一份权限状态、原因、检查/暂停/复查时间与修订号。
- `routes`：各真实 ID 的目录或人工测试证据，避免用家族支持推断未出现的模型。
- `models`：保留旧 5.5 三档格式的兼容投影；不是当前权限管理的事实来源。
- 根级账号身份摘要与复查租约继续用于内部并发保护，不向面板返回。

读取旧 JSON 时在内存中转换，不触发写入。仅当旧三档记录完整且状态、检查时间、暂停期限、
复查时间和原因一致时，才将其提升为 5.5 家族证据；冲突或不完整记录保持待确认。
旧数据不能建立 4.6 支持。有效查询或生成观察发生后，才按现有原子更新流程写入 v2。
若旧版本写入者改变了 v2 中的兼容投影，读取时清空不再可信的家族/路由证据，等待重新确认。
格式损坏或未知 schema 不产生支持证据。

观察写入同时检查凭证代次、完整内容版本与权限修订号。替换凭证和删除后重建使旧证据失效；
正常 token 刷新保留同账号限制，但刷新前的网络结果不能覆盖新内容。
旧目录结果不能清除其发出后发生的 404，旧 404 不能覆盖页面重新确认的支持证据。
模型目录查询也将快照绑定到实际使用的凭证内容版本。

## 面板接口与使用

桌面和移动端均提供版本选择（默认 Opus 5.5）及统一权限筛选；每个版本仅显示一枚徽标和
一组详情时间。权限总览、逐凭证结果及批量报告使用后端家族证据，不在浏览器组合旧三档状态。
权限表示目录支持，不保证剩余额度或生成已验证。

`GET /creds/status?mode=antigravity` 支持：

| 参数 | 可选值 | 默认值 |
| --- | --- | --- |
| `model_access_family` | `claude-opus-5-5`、`claude-opus-4-6` | `claude-opus-5-5` |
| `model_access_filter` | `all`、`supported`、`unavailable`、`unknown` | `all` |
| `model_access_tier` | `any`、`all_tiers`、`low`、`medium`、`high` | `any`；仅兼容接受，已废弃权限档位语义 |

权限在后端分页前筛选。`total/has_more` 对应筛选结果；总览遵循状态、错误码、额度组、
订阅 Tier 和备注筛选，不受权限筛选影响，覆盖所有匹配分页。`unknown` 包括未知及已过期支持。
“暂不可用”是既有暂停，暂停到期不会变成支持。

增量响应字段：

- `items[].model_access_families`：以两个家族 ID 为键的安全状态。
- `model_access_summary.family_counts`：每个家族的 `supported/unavailable/unknown` 数量；
  同时保留总览 `total/checked_at` 和旧 `counts` 字段。旧五种 counts 为 5.5 家族计数兼容投影。
- 单凭证额度/测试与批量结果保留原格式并增加 `model_access_families`；批量顶层增加同结构
  `model_access_summary`，失败项计入已有证据或未知，不伪造查询成功。
- `model_access_state` 保留旧三档安全投影；`model_access_update` 保留更新结果。

存储支持且可批量读取家族状态时，面板声明 `antigravity.model_access.family_filter`。
无能力时默认列表仍可读取，不提供家族状态；显式权限筛选或 4.6 家族筛选返回 501。
前端禁用相应筛选且提示状态暂不可用，不从旧 `model_access_state` 推断家族支持。
非法参数返回 400；Gemini CLI 非默认 Opus 参数返回 400，默认列表维持原路径。
已有 `antigravity.model_access.protection` 继续表示业务权限保护能力。

列表为数据库只读快照，不请求 Google、不刷新 OAuth、不修改权限、冷却或统计；
公开状态只含状态、原因、检查及暂停时间，不含 token、完整凭证、身份摘要、租约或修订号。
摘要与权限是独立只读快照，并发变化可能短暂显示旧状态，生成最终准入仍执行原子检查。

桌面“选择全部筛选结果”按一次捕获的筛选条件跨页收集，并替换已有选择；本页全选仍只选择本页。
移动端维持已有本页选择。批量额度/权限检测复用目录查询并同步既有共享额度组，不发送模型生成。
人工单模型测试仍固定所选凭证和精确模型。

Management schema 保持 1.4，管理动作枚举不变；本次不恢复统一管理开发，manager 无需动作：
`no_counterpart_action`。

## 回滚与验证边界

回滚只恢复代码，保留 `model_access_state` 原数据；不要删除字段、降级 JSON 或改写生产凭证。
旧程序不具备本次版本家族权限和 4.6 恢复语义，可能拒绝 4.6 或写入旧投影；不应将不同语义的
版本同时作为一致权限系统运行。再次升级后，受旧写入影响的证据将待确认，须重新查询目录。
只回滚到已知能安全处理该字段的版本；不能把回滚后缺少保护误认为等价恢复。

验证使用临时 SQLite、SQL/Mongo 驱动替身和模拟 Google 响应，不访问生产数据库。
覆盖版本隔离、精确路由、期限、旧 JSON 读取、并发栅栏、筛选分页、批量计数与实际前端函数。
本次浏览器工具无可用浏览器，尚无本次真实浏览器截图或点击验收；Node 渲染检查不能替代该项。
