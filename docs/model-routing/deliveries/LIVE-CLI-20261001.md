## 503：已排除与仍未知的部分

原生 Gemini 客户端观察到的脱敏错误为：

```json
{
  "error": {
    "code": 503,
    "message": "The service is temporarily unavailable. Please try again later.",
    "status": "UNAVAILABLE"
  }

```

OpenAI 非流式返回 `service_unavailable_error`，Anthropic 非流式返回 `overloaded_error`。这些是公开安全错误边界，不保留全部内部原因，不能据此确定 Google 原始返回码。

## 抗截断流的 502

现有服务 stderr 堆栈落在 `src/converter/anti_truncation.py:356`，实际条件为 `scoped_parts and text_modified`。

- 这是第一轮中清理 `[done]` 改变正文后，随后遇到带作用域内容的保护性拒绝；不是跨轮拒绝，跨轮分支在更早的位置。
- 作用域可能来自签名、grounding/citation 或多候选结构；被拒绝的上游帧没有保存，不能确定具体类型。
- 已到达客户端的正文帧没有这些字段，也没有 finishReason 或 DONE；不能据此声称合法 STOP 被错误删除。
- 该边界属于当前验收文档已有的安全拒绝条件，但实际模式可用性测试仍必须单列为失败，不能因为“预期安全拒绝”而把生成测试改成通过。

后续若修复，应先用合成的签名/引用/多候选帧复现，再决定缓冲未修改原文或明确拒绝不支持的组合；不能简单删除此保护或丢弃引用、签名来让测试表面通过。本轮只分析，没有实施修改。
