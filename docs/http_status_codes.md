# gcli2api HTTP 状态码文档

本文档详细说明 gcli2api 在代理请求时返回的各个 HTTP 状态码含义、触发条件及处理逻辑。

---

## 200 — 请求成功

- 上游 Google API 正常返回结果
- 流式请求：返回 SSE 数据流
- 非流式请求：返回完整 JSON 响应

---

## 429 — 速率限制 (Rate Limited)

- **来源**：上游 Google API 返回
- **行为**：
  - 解析响应中的 `quotaResetTimeStamp` 或 `quotaResetDelay` 提取冷却时间
  - **有冷却时间**：记录错误 → 切换到新凭证 → 自动重试
  - **无冷却时间**：**保留当前凭证** → 直接重试（不切换凭证）
  - 重试次数耗尽后，**返回原始 429 响应给调用者**
- **不会触发 auto-ban**

---

## 503 — 服务不可用

- **来源**：上游 Google API 返回
- **行为**：与 429 完全相同的处理逻辑
  - 有冷却时间 → 切换凭证重试
  - 无冷却时间 → 保留凭证重试
  - 重试耗尽 → 返回原始 503

---

## 403 — 凭证被禁止（默认 Auto-Ban 错误码）

- **来源**：上游 Google API 返回（通常是 project 被禁用、权限不足等）
- **行为**：
  - 触发 **auto-ban**：自动禁用该凭证（`disabled=True`）
  - 切换到新凭证 → 自动重试
  - 重试耗尽 → 返回原始 403 响应
- **可配置**：`AUTO_BAN_ERROR_CODES` 默认 `[403]`，可通过环境变量 `AUTO_BAN_ERROR_CODES` 或面板配置修改

---

## 404 — 模型不存在（Preview 特殊处理）

- **来源**：上游 Google API 返回
- **行为**：分两种情况
  - **请求的是 preview 模型**（模型名包含 "preview"）：
    - 将该凭证的 `preview` 状态设为 `False`
    - 切换到支持 preview 的凭证 → 自动重试
    - 重试耗尽 → 返回原始 404
  - **非 preview 模型的 404**：
    - **不重试**，直接返回原始 404 响应

---

## 500 — 服务内部错误

**gcli2api 自身生成**（非上游返回），以下情况返回 500：

| 场景 | 返回内容 |
|------|---------|
| 无可用凭证（首次获取） | `{"error": "当前无可用凭证"}` |
| 重试时凭证耗尽 | `{"error": "当前无可用凭证"}` |
| 请求准备失败（缺少 token/project_id） | `{"error": "准备请求失败: ..."}` |
| 所有重试均因异常失败 | `{"error": "流式请求异常: ..."}` 或 `{"error": "请求异常: ..."}` |

---

## 其他错误码（透传）

除 429、503、403（auto-ban 码）、404（preview）之外的所有错误码（如 400、401 等来自上游的响应）：

- **不重试**，直接记录错误并 **透传原始响应** 给调用者
- 错误会被记录到凭证的 `error_codes` 和 `error_messages` 中

---

## 处理流程

```
请求到达 gcli2api
    │
    ├── 获取凭证 → 无可用凭证 → 返回 500 {"error": "当前无可用凭证"}
    │
    ├── 转发到 Google API
    │       │
    │       ├── 200 → 返回成功
    │       ├── 429/503 → 重试(最多N次) → 耗尽后透传原始错误码
    │       ├── 403(auto-ban) → 禁用凭证 → 重试 → 耗尽后透传 403
    │       ├── 404+preview模型 → 设preview=False → 重试 → 耗尽后透传 404
    │       └── 其他错误码 → 不重试，直接透传
    │
    └── 异常(网络等) → 重试 → 耗尽后返回 500
```

---

## 相关配置项

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `auto_ban_enabled` | `False` | 是否启用自动封禁 |
| `auto_ban_error_codes` | `[403]` | 触发自动封禁的错误码列表 |
| `retry_enabled` | 面板配置 | 是否启用自动重试 |
| `retry_max_retries` | 面板配置 | 最大重试次数 |
| `retry_interval` | 面板配置 | 重试间隔（秒） |

环境变量 `AUTO_BAN_ERROR_CODES` 可覆盖数据库配置，格式为逗号分隔的数字（如 `"400,403"`）。
