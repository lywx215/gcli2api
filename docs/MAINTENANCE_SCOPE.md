# 当前维护范围

更新日期：2026-09-22。依据：所有者明确要求“Gemini CLI相关内容将不再维护”。

## Gemini CLI：停止维护

- 不再安排Gemini CLI专属功能开发、模型适配、缺陷修复、性能优化或发布验证。
- 现有代码、接口、控制面板入口、配置、测试及凭证数据保留。本决定不要求删除、禁用、
  停服或数据迁移。
- 此前发现的Gemini CLI部分流输出后重放问题只作历史记录，不再列为待修复项。
- 旧审计、参考项目和fork中的Gemini CLI改动不再形成后续任务；恢复维护须所有者另行
  明确指示。

## Antigravity：后续改善建议

以下为评估后的候选顺序，尚未开始实施：

1. 修复上传结果真实性：存储失败应向上传递，成功数量必须与实际落库一致。
2. 增加Antigravity响应头、首个有效正文和流空闲超时，并约束总重试预算。
3. 修复同一额度族连续进入冷却时重复结算、覆盖上一轮统计的问题。沿用经确认的额度族
   边界，不直接照搬fork将全部Gemini模型归为一族的实现。
4. 限制ZIP条目数、解压总量和写库并发，控制批量导入资源消耗。
5. 先测量Antigravity凭证选择和网络开销，再评估有界候选查询及HTTP连接复用。
6. 终身累计统计作为低优先级可选项；实施前另行确定统计口径、迁移与回滚方案。

上传、存储、HTTP客户端及转换器中的共享代码，只在Antigravity改善确有需要时修改。
保留现有兼容性与回归保护，不将共享改动扩展为Gemini CLI专属维护。不修改真实凭证、
生产数据库或Volume；如后续任务确需迁移，仍须按仓库约束单独定义方案。
