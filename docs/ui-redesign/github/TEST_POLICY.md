# 页面人工验收与最小自动检查

2026-10-15，用户要求尽量减少无用测试，页面确认主要由人工完成。本文件取代旧任务中要求详细页面自动测试、每批完整回归的验收安排；功能要求、接口、文件归属和安全约束不变。

## 自动检查保留范围

- 类型检查：在模块交付或最终集成节点执行；同一源码结果复用，不在每个小任务反复运行。
- 生产构建与六页产物检查：最终集成后统一执行一次；后续仅在源码变化或真实失败需要时重跑。
- 旧接口兼容、跨凭证/会话隔离、危险操作确认及单次提交：仅对本次实际修改或已发现缺陷保留少量针对性自动检查。同一风险优先在最直接的一层覆盖，不在 API、hook、组件、页面逐层重复造矩阵。
- 权限、撤权、文件范围、读写冲突和交付哈希检查继续执行。这些分派器约束不因减少页面测试而放宽。

不新增样式快照、逐字段 DOM/文案断言、页面交互大矩阵、与实现逐行对应的测试或没有失败依据的全量重跑。不规定新增测试数量/覆盖率目标；已有通过的测试保留，不删测试、不降低断言、不把跳过写成通过。未触及的后端大矩阵不运行。全量前端套件不作为本轮默认页面确认门槛，已知失败继续如实列出。

## 人工页面确认

由客户/指定验收人检查六页的布局、文案、配色、状态、弹窗、表格、按钮及主要流程；重点确认额度卡片的真实5H/周数据、比例与未知状态，以及查看额度、导入、维护、设置保存等入口。桌面和手机各覆盖主要流程，检查溢出、键盘/焦点和错误提示；不预先扩成浏览器×尺寸×状态的全排列。

交付可访问预览、简短操作清单和已知限制。开发者提供预览不等于客户已确认；验收结果记录确认人、实际版本、通过项/问题。发现问题后修复并复查受影响流程；只有可复现且有回归风险时才补最小自动用例。

## 两个 Mac 模块

- LegacyModelQuota：展示、分组、比例、倒计时及名称切换由人工确认；自动检查只聚焦显式操作目标正确，以及失效 owner 的回调/计时器不操作新 owner。
- AgQuotaEvidence：证据展示、状态与确认框由人工确认；自动检查只聚焦取消零请求、一次有效确认只发送一次，以及旧凭证/会话/票据和晚到结果不能影响新上下文。不要为所有显示字段建立组合测试。
- 外部作者同一次模块请求完成源码和必要的最小关键回归，不额外分派测试专项。Codex 只检查交付和运行必要命令，不代写前端源码或测试。

## 执行与记录

本策略供下一份尚未消费的合法请求采用；不中断或重放正在执行/已消费的请求，不扩大本机授权。模块交付后不要求 Windows 与 Mac 对同一源码重复执行同一命令；只在父页面集成改变相关行为后补查受影响部分。

GitHub 只记录协调，不启动模型。Actions 当前关闭，本策略不启用云端CI、不新增工作流或测试工程。此文档更新不运行页面/后端套件；只核对文档、JSON及契约/文件归属未变。Docker跳过，不部署。
