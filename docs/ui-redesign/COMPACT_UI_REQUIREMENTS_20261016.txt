2. 用户需要解决的问题（硬需求）
- 当前顶部统计、筛选及批量工具占用整个首屏，实际凭证内容难以看到。改善后首屏应优先展示实际工作内容。
- 全系统紧凑型显示，桌面按钮小型化；不是只处理截图中的一个局部。
- 六页、登录、导航、公共控件、表格、卡片、抽屉、弹窗风格一致。保留已确认功能与重要状态。
- 密度提高仍需可读、可点击、键盘可操作；手机与粗指针不照搬桌面极小尺寸；长名称、错误及200%缩放可用。
- 额度卡片继续保留CLIProxyAPI参考方向，5H/周额度、比例、重置和采集时间、刷新、未知及失败状态完整可见。
- 原有筛选、跨页选择、批量操作、停止、进度、结果详情、文件和邮箱工具全部可达，不能用删除功能达到紧凑效果。
- 原有暖灰风格和已确认操作习惯作为设计上下文；具体视觉处理与布局由Gemini决定。如其提案需要扩大到新主题/主题切换，应明确指出范围影响。
