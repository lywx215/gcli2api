# Shared dispatcher source distribution

These are byte-identical public source copies of the existing shared user-level dispatcher and role, supplied for Mac installation. This directory is not a project runner. Install and invoke the single user-level hook using the instructions in `docs/ui-redesign/github/DISPATCHER_MAC_INSTALL.md`; do not execute a parallel runner from this checkout.

No authorization, request, session, login, credential or database state is distributed. Installation and Issues do not grant model execution. Compare existing installed files before replacement; keep unrelated local configuration. The original Windows usage document is reference material, not a Mac command script.
